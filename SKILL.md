# Wearables Tech Frontiers (wtf)

This skill produces an on-demand signal brief for wearables and sports-health
R&D. It reads the central feed generated by GitHub Actions, applies user
preferences, and remixes only the returned JSON.

## Operating Model

- User digests are on demand. Do not create scheduled user pushes.
- Do not perform ad-hoc web search during digest generation.
- Do not refetch article URLs. Use only `items` from `prepare-digest.js`.
- Default feed path: `remote_feed`, with central RSS/API/Tavily results.
- Fallback feed path: `local_rss`, with local RSS plus the local openFDA subset.
- User overrides live in `~/.wtf/config.json`, `~/.wtf/sources.json`, and `~/.wtf/prompts/*.md`.
- The public source catalog is `config/sources.json`.

## First Run

Check whether `~/.wtf/config.json` exists with `onboardingComplete: true`.
If not, keep onboarding short:

1. Introduce the skill:

```text
I am wearables-tech-frontiers (wtf), an on-demand digest for wearables and sports-health signals.

I read the central feed and organize the result into Top Signals, Algorithm & Evidence, Clinical / Regulatory, Platform & API, Product / Market, and Worth Skimming.

I do not do scheduled pushes, runtime search, X/Twitter coverage, Chinese industry-media feeds, openFDA adverse-event reports, paid funding databases, or telemetry.
```

2. Ask for three defaults:
   - `windowDays`: 1 / 7 / 14 / 30
   - `language`: `en` / `zh` / `bilingual`
   - `categories`: any of `academic`, `vendor_research`, `industry_news`, `clinical_registry`, `regulatory`

3. Save the selected values to `~/.wtf/config.json`.

   Example:

```bash
mkdir -p ~/.wtf
cat > ~/.wtf/config.json << 'CFGEOF'
{
  "windowDays": 7,
  "language": "en",
  "categories": ["academic", "vendor_research", "industry_news", "clinical_registry", "regulatory"],
  "onboardingComplete": true
}
CFGEOF
```

4. Run the digest immediately.

## Digest Run

Run:

```bash
node "${CLAUDE_SKILL_DIR:-$PWD}/scripts/prepare-digest.js"
```

Map one-time user wording to CLI args:

- `past N days` -> `--days=N`
- `academic only` -> `--category=academic`
- `local only` or `skip remote` -> `--no-remote`

The script output is the only allowed content pool:

- `items` and `groupedByCategory`
- `prompts`
- `healthcheck`
- `scarcityTaxonomy`

If `stats.keptItems == 0`, say:

```text
No items matched the filters for the past [windowDays] days. Try `/wtf past 14 days`.
```

Then stop.

## Remix Rules

Follow the prompts returned by the script:

- `prompts.digest_intro`: structure, section mapping, Top Signals, healthcheck footer
- `prompts.summarize_papers`: academic items
- `prompts.summarize_official`: vendor research items
- `prompts.summarize_news`: industry news, vendor websearch, clinical registry, regulatory items
- `prompts.translate`: apply when `config.language` is `zh` or `bilingual`

Populate:

- `healthcheck.top3_categories`
- `healthcheck.top3_scores`
- `healthcheck.top3_rejected_candidates`

Language behavior:

- `en`: English only
- `zh`: Chinese only, keeping product names and technical abbreviations in English
- `bilingual`: Chinese first, paired with English where useful

## Configuration

When the user asks to persist a default, edit `~/.wtf/config.json` and confirm in one line.

Supported fields:

- `windowDays`: 1 / 7 / 14 / 30
- `language`: `en` / `zh` / `bilingual`
- `categories`: `academic`, `vendor_research`, `industry_news`, `clinical_registry`, `regulatory`

One-time requests such as `past 14 days` should use CLI args and should not change config.

For sources:

- Add a source URL to `~/.wtf/sources.json`; this forces `local_rss`.
- Show current sources by printing the merged public catalog and user catalog.

For prompts:

- Copy the relevant repo prompt to `~/.wtf/prompts/<name>.md`.
- Edit only the user override file.

## Debug

If the user says `debug` or `dump JSON`, rerun:

```bash
node "${CLAUDE_SKILL_DIR:-$PWD}/scripts/prepare-digest.js"
```

Output the full JSON, then briefly note:

- feed source: `remote_feed` or `local_rss`
- failed RSS/API sources
- Tavily center-run stats
- filter counts

## Absolute Rules

- Only use `items` from the script JSON.
- Every bullet must include a URL; drop items without URLs.
- Do not run web search or page-fetch tools during digest generation.
- Do not invent sources, categories, scores, dates, URLs, claims, sample sizes, or model details.
- Do not list a Top Signal again in later sections.
- Do not use hype.
- Top Signals category labels must match `scarcityTaxonomy.categories`.
